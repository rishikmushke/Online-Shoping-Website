Online Shopping Item Booking System

Description

A simple console-based Online Shopping Item Booking System developed using C programming. The program displays available products with their IDs and prices, allows the user to select an item and quantity, calculates the total amount, and collects the delivery address.

Features

- Display available shopping items
- Select an item using Item ID
- Enter required quantity
- Calculate total purchase amount
- Enter delivery address
- Display order confirmation
- Display estimated delivery information

How It Works

1. The program displays the available products.
2. The user enters the Item ID.
3. The user enters the required quantity.
4. The program calculates the total amount.
5. The user enters the delivery address.
6. The program displays the order confirmation.
